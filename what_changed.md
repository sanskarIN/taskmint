# RC7 implementation hardening already completed

The full implementation history is preserved in the earlier handoff and changelog. Current key runtime guarantees include:

## Task mutation safety

- TaskComposer synchronous duplicate-submit lock.
- TaskItem synchronous per-row mutation lock.
- App-wide exclusive task mutation gate covering create/edit/complete/reopen/archive/restore/delete/Undo/keyboard reorder/drag reorder.
- Pending task writes disable competing task rows/composer/Settings entry/global task shortcuts.
- Exclusive mutation gate always releases on failure paths.
- Same-file JSON/CSV import selection is cleared immediately after capturing the browser `File`, before async processing settles.

## Persistence/data integrity

- IndexedDB task/settings reads validated before React state.
- Repository task/settings writes validated before persistence.
- Complete task batches/replacements validated before transaction open.
- Duplicate task IDs rejected before bulk persistence.
- Multi-task writes are transactional.
- Backup restore is fully validated/normalized before the destructive transaction opens.
- Malformed startup data fails closed and remains untouched rather than being silently deleted/replaced by an empty writable app.

## Ordering/recurrence/import integrity

- Safe-integer manual-order allocation/comparison/normalization.
- Deterministic ID tie-breaker.
- Recurring next occurrence receives collision-free App-supplied order.
- CSV append receives a caller-provided order base after existing task maximum.
- Blank CSV records do not consume task quota while total input remains file-size bounded.
- Original CSV source row numbers remain accurate after blank records are skipped.

## Portability/security/privacy

- JSON backup schema v2 with strict validation.
- CSV `safe-text-v1` marked semantics plus legacy unmarked compatibility.
- Lossless structured tags for current CSV.
- Strict quote/header/enum/date/timestamp handling.
- Spreadsheet-formula neutralization for user-controlled CSV text.
- Fail-closed development diagnostic metadata and no arbitrary raw `Error.message` logging.
- Restrictive committed production CSP with Vite-only serve-mode relaxations.

## Accessibility/PWA

- active smart-view/project `aria-current` semantics;
- project controls inside navigation landmark;
- named search/filter group;
- keyboard ordering alternative to drag/drop;
- pending `aria-busy`/disabled semantics;
- modal focus containment/restoration;
- prompt/waiting service-worker update rather than automatic draft-destructive reload;
- serialized Update now activation.
